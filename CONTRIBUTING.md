# Как поучаствовать

Проект хобби-шный и навайбкоженный, так что порог входа низкий: нашли баг — откройте issue, есть идея — тоже issue, хотите поправить сами — pull request.

## Сообщить о баге

Пожалуйста, приложите:
- версию Windows (`winver`) и версию Haze;
- что делали, что ожидали, что получилось;
- скриншот, если это про внешний вид;
- содержимое `%APPDATA%\Haze\errors.log`, если он есть.

**Не прикладывайте** свой `settings.json` целиком — там путь к аватару, имя профиля и прочие личные мелочи.

## Собрать у себя

```bat
cd 0.1.0
npm install
npm start
```

Перед тем как прислать PR:
1. Проверьте вживую на своём рабочем столе — автотестов нет, вся проверка глазами.
2. Закрывайте Haze через трей или `npm run stop`, а не через диспетчер задач.
3. Держитесь стиля окружающего кода: чистый JS без фреймворков, короткие комментарии «зачем», а не «что».
4. Если меняется поведение — добавьте строчку в `CHANGELOG.md` в раздел следующей версии.

## Новая версия

1. Скопировать актуальные исходники в новую папку `X.Y.Z/` и поднять `version` в её `package.json`.
2. В этой папке: `npm install && npm run dist`, положить `dist\Haze.exe` рядом с `package.json` (или собрать на GitHub: *Actions* → «Сборка Haze.exe»).
3. Дописать `CHANGELOG.md` и ссылку на версию в `README.md`.

## Использование ИИ

Код можно (и нужно, раз уж так повелось) писать с ИИ-ассистентами. Главное — запускать и проверять результат, прежде чем отправлять.
