# ТЗ: «Cozy Desktop» — кастомизация рабочего стола под Windows

## Суть одним предложением
Приложение для Windows 10/11 в духе **Wallpaper Engine, но полное**: живые обои **+** интерактивные виджеты **+** кастомный курсор **+** кастомные иконки **+** док **+** верхняя панель **+** анимации. Всё в едином уютном пастельно-аниме стиле. Один инструмент, который полностью преображает рабочий стол.

## Платформа
Windows 10/11 (x64). Локально, без обязательного аккаунта, легковесно, не грузит систему.

## Референс стиля
Аниме-обои (живые), «матовое стекло» (frosted glass / blur), скруглённые карточки ~20px, мягкие тени, пастельная палитра (как на референсе — тёплый/зелёный варианты), виджеты в стиле iOS. Поддержка светлой и тёмной темы.

---

## Компоненты (по зонам экрана)

### 1. Слой живых обоев
- Видео / GIF / HTML / шейдер на заднем плане рабочего стола, **под иконками**.
- На Windows рисуется в слой обоев через инъекцию в `WorkerW` (технология как у Lively Wallpaper / Wallpaper Engine).
- Пауза при полноэкранных приложениях (экономия ресурсов).

### 2. Верхняя панель (top bar)
- Индикатор рабочего стола/воркспейса, системный трей (заряд %, звук, Wi-Fi, Bluetooth).
- Погода (°C), дата и время, раскладка клавиатуры.
- Индикатор «сейчас играет» / «нет медиа», индикатор записи экрана.

### 3. Виджеты (перетаскиваемые, с реальными данными)
- **Профиль:** аватар, имя пользователя, аптайм системы, строка статуса, кнопки **Lock / Настройки / Выключение**.
- **Часы + мировое время:** большие часы, дата, город, 3–4 часовых пояса с UTC-смещениями.
- **Большие часы** (крупные цифры в две строки) + **плитка даты** (месяц/день недели/число).
- **Музыкальный плеер:** обложка, трек, исполнитель, прогресс, кнопки ⏮⏯⏭ — данные из **Windows SMTC** (System Media Transport Controls), работает со Spotify/браузером/любым плеером.
- **Погода:** температура, состояние, город, влажность, ветер, восход/закат — через погодный API (OpenWeatherMap/Open-Meteo) по геолокации или вручную заданному городу.
- **Системные метрики:** CPU %, RAM %, батарея % (кольцевые индикаторы) — реальные данные через системные API. Опционально: температура, диск, сеть.
- **Конвертер изображений:** drag-and-drop картинок, конвертация PNG/JPG/WEBP/AVIF/BMP/PDF/TIFF, выбор формата на выходе.

### 4. Док (нижняя панель)
- Отдельная авто-скрывающаяся панель с закреплёнными приложениями и индикаторами запущенных.
- Анимация наведения (увеличение иконок).

### 5. Кастомный курсор
- Установка схемы курсора (`.cur`/`.ani`) в тему, подходящую под эстетику; смена в один клик, откат к системному.

### 6. Кастомные иконки
- Пак иконок «как на телефоне» для ярлыков рабочего стола; подмена/наложение иконок, сетка-лаунчер.

### 7. Анимации
- Плавные появления виджетов, микроанимации при наведении, переходы тем. Уважать `prefers-reduced-motion` / настройку «меньше анимаций».

### 8. Движок кастомизации (настройки)
- Перетаскивание и сохранение раскладки виджетов.
- Выбор обоев, темы, палитры, включение/выключение отдельных виджетов.
- Автозапуск с системой, иконка в трее, профили/пресеты оформления.

## Технический подход (Windows)
- **Оболочка:** Electron или **Tauri** (легче) + WebView2; UI на HTML/CSS/JS — для попиксельного контроля стиля.
- **Окна виджетов:** прозрачные, «always on desktop», опционально click-through, без рамок.
- **Обои:** рендер в `WorkerW` (как Lively Wallpaper — открытый, можно взять за основу слоя обоев).
- **Данные:** системные метрики через нативные библиотеки; «сейчас играет» через SMTC; погода через API; время/пояса локально.

### Встроенный браузер (правила сессии `persist:browserview`)
- Сайты живут в собственной сессии с отдельными cookie/кэшем, изолированной от окон Haze.
- **Разрешения — запрет по умолчанию.** Сайтам доступны только «полноэкранный режим» и «захват указателя» (видеоплееры, карты, игры); геолокация, уведомления, камера/микрофон, чтение буфера обмена отклоняются, отказ пишется в errors.log.
- **Загрузки — только через диалог сохранения.** Тихая загрузка в «Загрузки» отключена: при клике по ссылке на скачивание открывается системный диалог «Куда сохранить», отмена диалога = отмены загрузки.
- **Бюджет окон:** не больше 10 открытых сайтов-оболочек одновременно; бюджет общий для плиток лаунчера и ссылок, открытых самим сайтом (window.open) — это один и тот же слой `browser.js`. Обычные программы лаунчера запускаются независимо от этого бюджета.
- **Производительность:** ограничение FPS обоев, пауза в фоне, лёгкий расход RAM/CPU.

## Этапы (MVP → дальше)
1. **MVP:** слой живых обоев + 3–4 базовых виджета (часы, погода, системные метрики, плеер) + темы и перетаскивание.
2. **Фаза 2:** верхняя панель + док.
3. **Фаза 3:** кастомный курсор + иконки + конвертер + пресеты оформления.

## Чего НЕ делаем (границы)
- Не требуем онлайн-аккаунт, не шлём данные наружу без нужды (только погодный API).
- Не переписываем проводник Windows — работаем слоями поверх/позади, не ломая систему.
- **Один монитор.** Верхняя панель, док, виджеты и «живое стекло» работают только на основном мониторе (app bar регистрируется на нём, область виджетов — его рабочая область). Обои растягиваются на весь виртуальный рабочий стол. Поддержка нескольких мониторов — отдельная задача на будущее.

## Как выбраться, если что-то пошло не так
- **Ctrl+Alt+H** — открыть настройки в любой момент, даже в игровом режиме, когда всё скрыто. Игровой режим «Всегда» выключается и в меню значка Haze в трее.
- Если Haze был убит (Диспетчер задач, сбой, отключение питания) со скрытой панелью задач или иконками, при следующем запуске он сначала вернёт их (метка `running.lock` в `%APPDATA%\Haze`). Без запуска Haze то же делает `scripts
estore.cmd` (`electron app --restore`).
- Сборка: `asar` выключен намеренно — PowerShell-помощники (`*.ps1`) запускаются внешним `powershell.exe` и должны лежать обычными файлами. Нативный помощник `haze-sys.exe` (Rust, `app/native/haze-sys`) кладётся в ресурсы exe через `extraResources`; если его нет или он раз за разом падает, Haze работает на `.ps1`. Electron закреплён точной версией в `package.json`, чтобы локальная сборка и сборка в GitHub Actions не расходились.
