# Haze — приложение

Electron-приложение: живые обои, виджеты, верхняя панель и док для Windows.
Запуск в режиме разработки: `npm start` (или `..\start.cmd` из папки версии). Проверки:
`npm run lint` (исходники и тесты), `npm test` (node --test, без запуска
Electron). Документация — в `..\docs\` (ARCHITECTURE.md, SPEC.md).

Нативный помощник `native/haze-sys` (Rust) собирается отдельно:
`cargo build --release` в его папке. Без него Haze работает на PowerShell-скриптах.

## Почему в `package.json` есть `allowScripts`

`"allowScripts": { "electron@45.0.0": true }` разрешает postinstall-скрипт
только Electron'а: он скачивает бинарник под текущую платформу. Это
единственный пакет со скриптами, которому это нужно; всё остальное ставится
без выполнения кода из пакетов. Версия закреплена точной (`45.0.0`), чтобы
локальная сборка и сборка в CI не расходились (см. SPEC.md, «Сборка»).
