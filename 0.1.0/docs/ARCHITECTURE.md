# Как устроен Haze

Короткая карта кода для тех, кто полезет внутрь. Код писался итеративно в паре с ИИ, поэтому местами он «вырос», а не спроектирован, — но структура ниже держится.

## Общая схема

Haze — Electron-приложение из нескольких прозрачных окон без рамок. Каждое окно — отдельная HTML-страница в `src/renderer/`, а вся работа с Windows идёт из главного процесса `src/main/`.

```
            ┌──────────────── главный процесс (src/main) ────────────────┐
            │ main.js — окна, трей, IPC, настройки, правила «кто кого    │
            │           перекрывает», полноэкранные игры                 │
            │ desktop.js ── koffi → user32/dwmapi/shell32 (WinAPI)       │
            │ psbridge.js ── PowerShell-помощники (status/media .ps1)    │
            └───────────────▲───────────────────────────▲────────────────┘
                            │ IPC через preload.js       │
  ┌───────────┬─────────────┼─────────┬─────────────┬───┴──────┬──────────┐
  wallpaper   widgets       topbar    dock          settings   browser
  (под        (на уровне    (app bar  (низ экрана,  (окно      (окно для
  иконками)   рабочего      на краю   авто-скрытие) настроек)  сайтов из
              стола)        экрана)                            лаунчеров)
```

## Главный процесс — `src/main/`

| Файл | Что делает |
|---|---|
| `main.js` | Точка входа: создаёт окна, трей, IPC-обработчики, применяет настройки, дважды в секунду проверяет, не закрыт ли экран развёрнутым/полноэкранным окном (пауза обоев, прятанье панели и дока). Единственный экземпляр; `--quit` просит запущенную копию закрыться. |
| `settings.js` | Настройки в `%APPDATA%\Haze\settings.json`. `DEFAULTS` — полный список ключей; сохранённое мёржится поверх, так что новые ключи появляются сами. |
| `desktop.js` | Вся магия WinAPI через [koffi](https://koffi.dev/): встраивание окна обоев в `WorkerW`, удержание виджетов на уровне рабочего стола, список окон для дока, скрытие панели задач, виртуальные рабочие столы, раскладка клавиатуры, исключение окон из захвата экрана. |
| `topbar.js` | Регистрирует панель как app bar (резервирует полосу экрана, как панель задач). |
| `dock.js` | Окно дока у любого края экрана, автоскрытие, запущенные приложения, программы из трея. |
| `psbridge.js` | Запускает PowerShell-скрипт как долгоживущего помощника: JSON-строки на stdout, команды на stdin. |
| `status.ps1` | Громкость (Core Audio), сеть, Bluetooth, микрофон/камера. Команды `mute`, `vol N`, `volstep ±N`. |
| `media.ps1` / `media.js` | «Сейчас играет» через Windows SMTC и кнопки плеера. |
| `tray.ps1` | Какие программы сейчас живут в системном трее. |
| `phone.ps1` | Данные для виджета телефона (USB/MTP, заряд Bluetooth-устройств). |
| `system.js` | CPU / RAM / диск / батарея. |
| `weather.js` | Погода из Open-Meteo (без ключа). |
| `feeds.js`, `hltv.js` | Данные инфо-виджетов: киберспорт (Liquipedia, HLTV, VLR), акции, спорт, новости. HLTV за Cloudflare, поэтому грузится в скрытом окне Chromium. |
| `clockwork.js` | Будильники и таймер выключения — в главном процессе, чтобы работали при любом состоянии окон. |
| `wallpaperengine.js` | Дружба с Wallpaper Engine: находит его через Steam и управляет через `-control`. |
| `browser.js` | Окно-браузер в стиле Haze для сайтов из панелей быстрого запуска. |
| `appicons.js` | Иконки программ и цели ярлыков для дока и лаунчеров. |

## Окна — `src/renderer/`

| Папка | Окно |
|---|---|
| `wallpaper/` | Живой фон: шейдер, видео, картинка. |
| `widgets/` | Все виджеты в одном прозрачном окне. `widgets.js` — раскладка, перетаскивание, масштаб; остальные файлы — отдельные виджеты и иконки. |
| `glass/` | Вспомогательное окно для «живого стекла» поверх Wallpaper Engine. |
| `topbar/` | Информационная панель. |
| `dock/` | Док. |
| `settings/` | Окно настроек. |
| `welcome/` | Окно знакомства при первом запуске (первый запуск = ещё нет `settings.json`). |
| `browser/` | Панель инструментов встроенного браузера. |
| `shared/` | Тема и палитры (`theme.css/js`), пресеты раскладок, список городов, сайты погоды. |

`src/preload.js` — единственный мост: выставляет в окна объект `window.cozy` с методами (`getSettings`, `statusCommand`, `openSettings`, …). Имя `cozy` осталось от прежнего названия проекта «Cozy Desktop».

## Отладка

- Ошибки главного процесса пишутся в `%APPDATA%\Haze\errors.log`.
- Переменная окружения `COZY_CAPTURE=<папка>` — через 8 секунд после старта Haze сохранит PNG каждого слоя (обои, виджеты, панель, док). Удобно проверять вёрстку без скриншотов экрана.
- Перезапуск из исходников: `npm run stop`, потом `npm start`. Не убивайте процесс принудительно — app bar и скрытая панель задач останутся «висеть».

## Первый запуск

`settings.isFirstRun()` — нет файла настроек. Тогда `main.js → firstRun()`: если работает Wallpaper Engine, обои переключаются на него; настройки сохраняются (чтобы знакомство было один раз) и открывается окно `welcome/`.

## Сборка

`npm run dist` → `dist\Haze.exe` (electron-builder, цель `portable`). То же самое на GitHub делает `.github/workflows/build.yml`. `asar` выключен намеренно: PowerShell-скрипты из `src/main` запускаются внешним `powershell.exe`, и им нужны настоящие файлы на диске. Конфиг — секция `build` в `package.json`.
