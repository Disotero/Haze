# История изменений

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-10-23

Первая публичная версия. Всё, что было сделано за время вайбкодинга, одним релизом.

### Добавлено
- Живые обои под иконками рабочего стола: встроенный шейдер, видео, GIF, картинки; совместимость с Wallpaper Engine и «живое стекло» поверх него.
- Виджеты: профиль, мировое время, большие часы, плеер (SMTC), погода (Open-Meteo), системные метрики, календарь с заметками, аналоговые часы, заметки, задачи, помидоро, сеть, цитата, фоторамка, поиск, конвертер изображений, киберспорт, акции, спорт, новости, телефон, панели быстрого запуска.
- Пресеты раскладки виджетов и пользовательские пресеты.
- Информационная панель (сверху / снизу / сбоку): звук, сеть, Bluetooth, батарея, погода, рабочие столы, часы, раскладка, «сейчас играет», «Не беспокоить», игровой режим, будильники, таймер выключения.
- Ползунок громкости, выезжающий при наведении на значок звука (отключается в настройках).
- Док с закреплёнными и запущенными приложениями, кнопкой «Пуск» и значками программ из трея; режим скрытия панели задач Windows.
- Темы, палитры, стили панелей (стекло / сплошной / парящий / неон), выбор шрифта, режим «меньше анимаций» и режим для слабого ПК.
- Встроенный браузер для сайтов из лаунчеров.
- Будильники и таймер выключения/перезагрузки/сна.
- Окно знакомства при первом запуске: что можно настроить и где, каждая карточка открывает нужный раздел. Повторно — «О Haze» → «Знакомство с Haze».
- Если при первом запуске работает Wallpaper Engine, Haze сразу выбирает его обои и не перекрывает их своими.
- Док ставится к любому краю экрана (снизу, сверху, слева, справа), с автоскрытием в этот край — как инфо-панель.
- Портативная сборка `Haze.exe` и её автосборка на GitHub Actions (вручную или по тегу `v*` с выкладкой в Releases).

### Исправлено
- Окна меню «Пуск» и поиска Windows больше не появляются в доке как запущенные приложения.
- Автозапуск в портативной сборке указывает на сам `Haze.exe`, а не на временную папку распаковки.
- Инфо-панель после переноса со стороны экрана наверх или вниз больше не сжимается до ширины боковой панели.
- Окно настроек больше не открывается серым пустым прямоугольником при первом открытии после запуска.
- Ползунок громкости выезжает плавнее и не дёргает соседние кнопки.
